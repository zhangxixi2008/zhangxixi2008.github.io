Linear Algebra 2.8 - 2.9 Subspace, dimension and rank

Section 2.8 : Subspace of R^n

A subspace of Rn\R^nRn if any set HHH in Rn\R^nRn that has 3 properties:

  1. The zero vector is in HHH
  2. For each uuu and vvv in HHH, then u+vu + vu+v is in HHH
  3. For each uuu in HHH and a scalar ccc, then cucucu is in HHH

Column Space

The Column space of a matrix AAA is the set Col  A\text{Col}\; AColA of all linear combinations of the columns of AAA.

If A=[a1⋯an]A=[a_1 \cdots a_n]A=[a1​⋯an​], with the columns in Rm\R^mRm, then Col  A\text{Col}\; AColA is the same as Span{a1,…,an}\text{Span}\{a_1,\dots,a_n\}Span{a1​,…,an​}.

The column space of an m×nm\times nm×n matrix is a subspace of Rm\R^mRm.

Null Space

The null space of a matrix AAA is the set Null  A\text{Null}\;ANullA of all solutions of the homogenous equation Ax=0Ax=0Ax=0

The null space of an m×nm\times nm×n matrix AAA is a subspace of Rn\R^nRn

Basic for a Subspace

A basic of a subspace HHH of Rn\R^nRn is a linearly independent set in HHH that spans HHH.

The set {e1,e2,…,en}\{e_1,e_2,\dots,e_n\}{e1​,e2​,…,en​} is called the standard basic for Rn\R^nRn.

The pivot columns of matrix AAA form a basis for the column space of AAA.

Warning:

Be careful to use pivot columns of AAA itself for the basis of Col  A\text{Col}\; AColA. DO NOT use the columns of an echelon form!!!

Section 1.9 Dimension and Rank

Coordinate System

Suppose the set B=b1,…,bpB={b_1,\dots,b_p}B=b1​,…,bp​ is a basis for a subspace HHH. For each xxx in HHH, the coordinates of xxx relative to the basis BBB are the weights c1,…,cpc_1,\dots,c_pc1​,…,cp​ such that x=c1b1+⋯+cpbpx=c_1b_1+\cdots+c_pb_px=c1​b1​+⋯+cp​bp​, and the vector in Rp\R^pRp:

is called the coordinate vector of xxx (relative to BBB) or the B-coordinate vector of xxx.

The Dimension of A Subspace

The dimension of a nonzero subspace HHH, denoted by dim H, is the number of vectors in any basis for HHH. The dimension of the zero subspace {0}\{0\}{0} is defined to be zero.

The rank of a matrix AAA, denoted by rank A, is the dimension of the column space of AAA. 2

The Rank Theorem

If a matrix AAA has nnn columns, then rank A+dim Nul A=n\text{rank A+dim Nul A}=nrank A+dim Nul A=n.

The Basic Theorem

Let HHH be a p-dimensional subspace of Rn\R^nRn.

  1. Any linearly independent set of exactly ppp elements in HHH is automatically a basis for HHH.
  2. Any set of ppp elements of HHH that spans HHH is automatically a basis for HHH.

The Invertible Theorem (continued)

AAA is an invertible matrix iff:

  1. The columns of AAA form a basis of Rn\R^nRn
  2. Col  A=Rn\text{Col}\;A=\R^nColA=Rn
  3. rank  A=n\text{rank}\;A=nrankA=n
  4. dim Nul  A=0\text{dim Nul}\;A=0dim NulA=0
