Linear Algebra Chapter 4.1 - 4.3 Vector Space I

Section 4.1 Vector Space and Subspaces

Definition

A vector space is a nonempty set VVV of vectors, on which are defined two operations: addition and multiplication by scalars.

Ten Axioms:

  1. If u,vu,vu,v in VVV, then u+vu+vu+v in VVV
  2. u+v=v+uu+v=v+uu+v=v+u
  3. (u+v)+w=u+(v+w)(u+v)+w=u+(v+w)(u+v)+w=u+(v+w)
  4. There is a zero vector 000 in VVV, and u+0=uu+0=uu+0=u
  5. For each uuu in VVV, there is a vector −u-u−u in VVV such that u+(−u)=0u+(-u)=0u+(−u)=0
  6. cucucu is in VVV
  7. c(u+v)=cu+cvc(u+v)=cu+cvc(u+v)=cu+cv
  8. (c+d)u=cu+du(c+d)u=cu+du(c+d)u=cu+du
  9. 1u=u1u=u1u=u

区分辨别：Field 和 Vector Space

Field有乘法逆元，而Vector Space没有。Field有乘法的定义。

Field本质上是对Scalar的操作，而Vector Space是对Vector中Addition的操作。Vector Space讨论的是Scalar作用到Vector上的情况。

Subspaces

Definition

A subspace of a vector space VVV is a subset HHH of VVV that:

  1. The zero vector of VVV is in HHH
  2. HHH is closed under vector addition.
  3. HHH is closed under multiplication by scalars.

A Subspace Spanned by a Set

Theorem 1

If v1,…,vpv_1,\dots, v_pv1​,…,vp​ are in a vector space VVV, then Span{v1,…,vp}\text{Span}\{v_1,\dots, v_p\}Span{v1​,…,vp​} is a subspace of VVV.

  1. Span is a way to guarantee to generate a vector space which contains all the vectors
  2. Span is a way to generate the smallest vector space
  3. The smallest means the the minimum dimension

Section 4.2 Null Space, Column Spaces, Row Spaces, and Linear Transformations

The Null Space of a matrix

Definition

The null space of an m×nm\times nm×n matrix AAA, written as Nul A\text{Nul}\, ANulA, is the set of all solutions of homogeneous equation Ax=0Ax=0Ax=0.

Nul  A={x:x is in Rn and Ax=0}\text{Nul}\; A = \{x:x\ \text{is in } \R^n\,\text{and}\,Ax=0\} NulA={x:x is in RnandAx=0}

Nul A\text{Nul}\, ANulA 的本质是矩阵的丢失信息

Theorem 2

The null space of an m×nm\times nm×n matrix AAA is a subspace of Rn\R^nRn.

Equivalently, the set of all solutions to a system Ax=0Ax=0Ax=0 of mmm homogeneous linear equations in nnn unknowns is a subspace of Rn\R^nRn.

The solutions to Ax=bAx=bAx=b is not a vector space, as 000 is not in.

The Column Space of a Matrix

Definition

The column space of an m×nm\times nm×n matrix AAA, written as Col A\text{Col}\, AColA, is the set of all linear combinations of the columns of AAA.

Col A=Span{a1,…,an}\text{Col}\,A=\text{Span}\{a_1,\dots,a_n\} ColA=Span{a1​,…,an​}

Theorem 3

The column space of an m×nm\times nm×n matrix AAA is a subspace of Rm\R^mRm.

Col A={b:b=Ax  for some x in Rn}\text{Col}\,A=\{b:b=Ax\;\text{for some}\, x\, \text{in} \,\R^n\} ColA={b:b=Axfor somexinRn}

The column space of an m×nm\times nm×n matrix AAA is all of Rm\R^mRm if and only if the equation Ax=bAx=bAx=b has a solution for each bbb in Rm\R^mRm.

  1. 与onto等价
  2. Column Space的本质就是Range！

The Row Space

Row A=Col AT\text{Row}\, A = \text{Col}\, A^T RowA=ColAT

Kernel and Range of a Linear Transformation

Definition

A linear transformation TTT from a vector space VVV into a vector space WWW is a rule that assigns to each vector xxx in VVV a unique vector T(x)T(x)T(x) in WWW, such that:

  1. T(u+v)=T(u)+T(v)T(u+v)=T(u)+T(v)T(u+v)=T(u)+T(v)
  2. T(cu)=cT(u)T(cu)=cT(u)T(cu)=cT(u)

The kernel (or null space) of TTT is the set of all uuu in VVV that T(u)=0T(u)=0T(u)=0

The range of TTT is the set of all vectors in WWW of the form T(x)T(x)T(x) for some xxx in VVV.

The kernel of TTT is a subspace of VVV.

Definition

Let HHH be a subspace of a vector space VVV. A set of vectors BBB in VVV is a basis for HHH if:

  1. BBB is a linearly independent set

  2. the subspace spanned by BBB coincides with HHH; that is,

    H=Span  BH=\text{Span}\; B H=SpanB

Theorem 5 The Spanning Set Theorem

Let S={v1,…,vp}S=\{v_1,\dots,v_p\}S={v1​,…,vp​} be a set in a vector space VVV, and let H=Span{v1,…,vp}H=\text{Span}\{v_1,\dots, v_p\}H=Span{v1​,…,vp​}.

  1. If one of the vectors vkv_kvk​ in SSS is a linear combination of the remaining vectors in SSS, then the set formed from SSS by removing vkv_kvk​ still spans HHH.
  2. If H≠{0}H\neq \{0\}H={0}, some subset of SSS is a basis for HHH.

Theorem 6

The pivot columns of a matrix AAA form a basis for Col  A\text{Col}\; AColA

Theorem 7

If two matrices AAA and BBB are row equivalent, then their row spaces are the same. If BBB is in echelon form, the nonzero rows of BBB form a basis for the row space of AAA as well as for that of BBB.
