C：数论 + 欧拉函数

给定 nnn 个正整数 aia_iai​。对于每个 1≤x≤1071\le x\le 10^71≤x≤107，定义 Fx=max⁡1≤i≤nφ(xai)F_x=\max_{1\le i\le n}\varphi(xa_i)Fx​=max1≤i≤n​φ(xai​)，其中 φ\varphiφ 是欧拉函数 n≤2×106n\le 2\times 10^6n≤2×106、ai≤107a_i\le 10^7ai​≤107。

手推式子可以得到

φ(xa)=φ(x)φ(a)gφ(g).\varphi(xa)=\varphi(x)\varphi(a)\frac{g}{\varphi(g)}. φ(xa)=φ(x)φ(a)φ(g)g​.

等价于求：

Fx=φ(x)max⁡i(φ(ai)gcd⁡(x,ai)φ(gcd⁡(x,ai))).F_x=\varphi(x)\max_i\left(\varphi(a_i)\frac{\gcd(x,a_i)}{\varphi(\gcd(x,a_i))}\right). Fx​=φ(x)imax​(φ(ai​)φ(gcd(x,ai​))gcd(x,ai​)​).

若 d1∣d2d_1\mid d_2d1​∣d2​，那么 d1d_1d1​ 的质因子集合包含于 d2d_2d2​ 的质因子集合，因此

d1φ(d1)≤d2φ(d2).\frac{d_1}{\varphi(d_1)}\le \frac{d_2}{\varphi(d_2)}. φ(d1​)d1​​≤φ(d2​)d2​​.

因此：从最大公因数改成共同约数

Fx=φ(x)max⁡d∣x(dφ(d)max⁡d∣aiφ(ai)).F_x=\varphi(x)\max_{d\mid x}\left(\frac d{\varphi(d)}\max_{d\mid a_i}\varphi(a_i)\right). Fx​=φ(x)d∣xmax​(φ(d)d​d∣ai​max​φ(ai​)).

内层和外层处理分别做一次Dirichlet前缀即可。

本题总结：

  1. 欧拉函数的类完全积性公式：φ(xa)=φ(x)φ(a)gφ(g).\varphi(xa)=\varphi(x)\varphi(a)\frac{g}{\varphi(g)}.φ(xa)=φ(x)φ(a)φ(g)g​.，这个东西要能做到手推
  2. 对于枚举gcd的题目，可以考虑枚举共同约数，然后利用性质证明枚举共同约数是不劣的（利用整除偏序上的单调性消除“最大公因数必须恰好相等”的限制）

D：观察性质 + 构造 + 分类讨论

给定一个长度为 nnn 的 A、B、C 字符串，1≤n≤2×1061 \le n \le 2 \times 10^61≤n≤2×106。每次查询给出一个区间 [l,r][l,r][l,r]，需要在其中找一段连续子区间，使 A、B、C 的出现次数两两不同，并使子区间长度最大；若有多个最长答案，输出任意一个，无解则输出 0 00\ 00 0。强制在线。

注意到一个很强的性质：若存在一个合法串S，前面添加≥3个字符且后面添加≥3个字符，则一定可以 扩展到更长的合法串。分讨得到最劣情况的构造是 BAASBAA

因此转化为分别求三种固定左端点、三种固定右端点的最优答案，再选最长即可。

接下来考虑固定左端点：跳过大量右端点。定义三种状态：

状态 含义
{a,a,a}\{a,a,a\}{a,a,a} 三种次数相等
{a,b,b}\{a,b,b\}{a,b,b}，a<ba<ba<b 两种次数并列最多
{a,a,b}\{a,a,b\}{a,a,b}，a<ba<ba<b 两种次数并列最少

对于Case1：

  1. 连续三个互不相同，直接跳过
  2. 连续三个相同，到情况2
  3. 连续有两个，完成！

对于Case2：

  1. 称次数为 aaa 的颜色为 X。如果末尾有一段连续的 X，长度为 kkk，删除其中任意数量。此时若还有字符，末尾一定属于某种次数为 bbb 的颜色。再删一个，变成 {a−k,b−1,b}.\{a-k,b-1,b\}.{a−k,b−1,b}.

  2. 唯一还要处理的是 k=0k=0k=0 且 b=a+1b=a+1b=a+1。

  3. 再删除一个字符：

    • 删除某种次数为 aaa 的颜色，得到 {a−1,a,a+1}\{a-1,a,a+1\}{a−1,a,a+1}，合法。
    • 删除次数为 a+1a+1a+1 的颜色，得到 {a,a,a}\{a,a,a\}{a,a,a}，转入三种相等状态。

对于Case3：

称次数为 bbb 的颜色为 X，设末尾连续 X 的长度为 kkk，计数差为

d=b−a.d=b-a. d=b−a.

只删除 X 时，另外两种次数始终相等，所以这些位置都非法。不过这里不能无条件删完整段：应先判断能不能在这段内到达三种相等。

如果 k≥dk\ge dk≥d： 只删 ddd 个 X，得到 {a,a,a}\{a,a,a\}{a,a,a}，转入相等状态。相等之后可能很快出现合法区间，不能把剩余的连续 X 也一并跳过。

如果 k<dk<dk<d： 删完整段后得到 {a,a,b−k}\{a,a,b-k\}{a,a,b−k}，且 b−k>ab-k>ab−k>a。下一字符属于某种次数为 aaa 的颜色，删一个得到

{a−1,a,b−k},\{a-1,a,b-k\}, {a−1,a,b−k},

三种次数严格递增，合法。

为什么这些状态转移真的是常数次？

  • 剩余不足三个字符：结束，无解。
  • 下一个三元组包含两种颜色：结束，找到合法答案。
  • 下一个三元组只有一种颜色：转入 {a−3,a,a}\{a-3,a,a\}{a−3,a,a}。

最后一种状态的高低差为 333。按照上一节“两种次数并列最多”的处理，无论末尾最少颜色的连续段是否为空，接下来删除一个最多颜色就合法；若区间耗尽则无解。因此不会再回到相等状态。

本题总结：

  1. 学会寻找强拓展性质，把任意端点压缩成常数个边界候选
  2. 非法计数状态安全跳转：只要发生跳转，思考发生了这种跳转是否会使得新的状态到达不了极端情况。

给定整数 nnn，求

∑i=1n∑j=in∑k=ijgcd⁡(i,k)gcd⁡(j,k)(jk)\sum_{i=1}^{n}\sum_{j=i}^{n}\sum_{k=i}^{j}\gcd(i,k)\gcd(j,k)\binom{j}{k} i=1∑n​j=i∑n​k=i∑j​gcd(i,k)gcd(j,k)(kj​)

对 998244353998244353998244353 取模后的结果。测试组数为 T≤10T\le 10T≤10，所有测试数据的 nnn 之和小于 5×1055\times 10^55×105。

经过一轮转化，我们要中间要计算这么一个式子（For all kkk）：

a(k)=∑i=1kgcd⁡(i,k),a(k)=\sum_{i=1}^{k}\gcd(i,k), a(k)=i=1∑k​gcd(i,k),

这是一个非常经典的套路！求gcd，可以枚举所有约数进行容斥！然后交换求和顺序之后用调和来均摊。具体的：

接下来我们还需要求这样一个东西：

g(n)=∑k=1n(nk)gcd⁡(n,k)a(k)g(n)=\sum_{k=1}^{n}\binom{n}{k}\gcd(n,k)a(k) g(n)=k=1∑n​(kn​)gcd(n,k)a(k)

涉及到这种形式，因为组合数显然搞不掉，所以必须拆开。里面的gcd同样用上面的套路处理（枚举约数 + 交换求和顺序）得到：

g(n)=n!∑x∣nφ(x)∑x∣ka(k)k!(n−k)!.g(n)=n!\sum_{x\mid n}\varphi(x)\sum_{x\mid k}\frac{a(k)}{k!(n-k)!}. g(n)=n!x∣n∑​φ(x)x∣k∑​k!(n−k)!a(k)​.

然后这个东西又是一个套路。

我们可以枚举 xxx，然后对 xxx 的倍数进行一个FFT卷积即可！

本题总结：

  1. 求gcd之和，可以枚举所有约数，然后容斥，系数就是欧拉函数，然后交换求和顺序
  2. 对于枚举约数，然后带组合数的东西。可以在确定约数的情况下对其所有倍数进行FFT卷积！

*E：二进制方波

给定长度为 nnn 的数组 aaa，其中 1≤n≤2×1051\le n\le 2\times 10^51≤n≤2×105、1≤k≤201\le k\le 201≤k≤20，且 0≤ai<2k0\le a_i<2^k0≤ai​<2k。对于每个掩码 S∈[0,2k−1]S\in[0,2^k-1]S∈[0,2k−1]，求最长连续区间 [l,r][l,r][l,r] 的长度，使得存在同一个整数 CCC，对所有 i∈[l,r]i\in[l,r]i∈[l,r] 均满足 ai&S=(C−i)&Sa_i\mathbin{\&}S=(C-i)\mathbin{\&}Sai​&S=(C−i)&S，其中 &\&& 表示按位与。

没太看懂

大致思想是，首先拆开每一位来维护。每一位的 C−iC-iC−i 的变化就是一个方波，然后维护一下当前这一段的波长和当前最长的连续，这样子可以处理出每一位。

然后是考虑全局处理。有一个非常大的性质是，当最高位的反转地方确定，所有低位的相位可以直接确定了。然后怎么做我就没看懂了。

到最后做一个高维前缀和就行。

本题总结：

  1. 利用方波图解决二进制问题
  2. 可以利用最高位确定，来推测出低位的相位

K：贪心策略 + FHQ Treap

数轴上有 nnn 个带编号的箱子，第 iii 个箱子初始位于 aia_iai​，需要在某个时刻到达目标位置 bib_ibi​，最终回到 aia_iai​。每次只能将一个箱子向左或向右移动 111 个单位，任何时刻两个箱子都不能重合，允许移动到负数位置。对每个 m=1,…,nm=1,\ldots,nm=1,…,n，独立求仅存在编号 111 到 mmm 的箱子时，完成全部要求的最少操作次数。不同箱子无须同时到达目标；若 ai=bia_i=b_iai​=bi​，则初始时已到达目标。n≤2×105n\le 2\times 10^5n≤2×105，1≤ai,bi≤1091\le a_i,b_i\le 10^91≤ai​,bi​≤109，初始位置两两不同，所有测试数据的 nnn 之和不超过 10610^6106。

考虑把前 mmm 个数取出，随后按 aia_iai​，排序。

假设这个箱子在全过程中要被移动到最右和最左 RiR_iRi​ and LiL_iLi​，那么答案的下界为 ∑2(Ri−Li)\sum2(R_i-L_i)∑2(Ri​−Li​)

Ri=max⁡(ai,bi,Ri−1+1)R_i=\max(a_i,b_i,R_{i-1}+1)Ri​=max(ai​,bi​,Ri−1​+1) 可以得到。

然后这个下界是可以得到的。首先把所有箱子都移到 RiR_iRi​，再全部移到 LiL_iLi​，在移中间即可。

现在的问题变成现在维护了。R和L的维护显然可以分开。

考虑fhq Treap。因为我们按 aia_iai​ 排序，所以就以 aaa 为key。

然后新的 RiR_iRi​ 是易求的，但是可能会影响后面。

但是影响的后面肯定是后面的一段前缀，这个东西直接在fhq Treap上二分就可以得到受影响的区间。此处我们可能要维护一下 Ri−iR_i-iRi​−i 之类的东西，而这个东西随着插入也会不断变化。

而这个受影响的区间会被整体赋值成等差数列 x,x+1,x+2,⋯x,x+1,x+2,\cdotsx,x+1,x+2,⋯，打个lazy_tag即可。

本题总结：

  1. 物体移动类的问题：考虑偏序关系的始终满足
  2. 先移动到右，再移动到左（可以先求必需覆盖的左右端点，再用一个合法构造证明总路程下界可达）
