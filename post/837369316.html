[ICPC Daily Practice 3] IC25上海选做（2题）

IC25上海I：贪心 + dp + 异或拆位贡献dp

给定一个长度为 nnn 的非负整数序列 aaa，定义序列价值为

Va=a1+an+∑i=1n−1(ai⊕ai+1),V_a=a_1+a_n+\sum_{i=1}^{n-1}(a_i\oplus a_{i+1}), Va​=a1​+an​+i=1∑n−1​(ai​⊕ai+1​),

其中 ⊕\oplus⊕ 表示按位异或。每次操作可以选择一个位置，将该位置的元素修改为任意非负整数，费用为 CCC。可以进行任意次操作，也可以不操作。设操作次数为 ppp，最终序列为 a′a'a′，求 pC+Va′pC+V_{a'}pC+Va′​ 的最小值，无需输出修改方案。输入包含多组测试数据，2≤n≤1052\le n\le10^52≤n≤105，0≤C<2190\le C<2^{19}0≤C<219，0≤ai<2180\le a_i<2^{18}0≤ai​<218，所有测试数据的 nnn 之和不超过 2×1052\times10^52×105。

贪心考虑这样一种更改策略，如果一个数被修改，则修改为 前一个数一定不劣。（Key observation）

因此最后一定是一段一段相同的。

考虑dp：

把后面那项拆开，然后 x=ajx=a_jx=aj​ 拿值域维护，我们得到：

fi=min⁡(gx+(ai⊕x))−(i+1)Cf_i=\min(g_x+(a_i\oplus x))-(i+1)C fi​=min(gx​+(ai​⊕x))−(i+1)C

现在有个关键的性质：dp中的异或贡献可以按位拆开算！

我们考虑转移时枚举 xxx 高9位，然后贡献到 xxx 的低9位。

枚举 0≤k<290\le k<2^90≤k<29

  • 贡献：fi+k−(i+1)Cf_i+k-(i+1)Cfi​+k−(i+1)C 贡献到 gai⊕kg_{a_i\oplus k}gai​⊕k​ （相当于提前变了低9位）
  • 转移：gai⊕(29k)+(29k)+iCg_{a_i\oplus(2^9k)}+(2^9k)+iCgai​⊕(29k)​+(29k)+iC 转移到 fif_ifi​ 里

复杂度 O(nV)O(n\sqrt V)O(nV​)

本题总结：

  1. 遇到“修改任意值”，先问能否消去具体修改值，比如变成前一项
  2. DP 交叉项有可分解结构时，让更新与查询分工（异或dp可以拆贡献！）

IC25上海L：构造 + 区间dp

给定一个长度为 nnn 的排列，可以反复将任意连续片段切分成两个相邻片段，也可以选择任意连续片段并交换其中最大值与最小值的位置。操作结束后，按原顺序合并所有片段。请统计最终能够得到的不同排列数量，并对 998 244 353998\,244\,353998244353 取模。 （n≤500n\le 500n≤500）

把一段看成一个尚未继续切分的整体时，真正作用于该整体的非平凡操作只有交换它的最大值和最小值。若后续继续切分，操作就转移到子区间中，由子区间递归处理。

因此一个极小区间只需要区分：没有交换、最小值参与交换、最大值参与交换。

定义三个dp:

  • fl,r,tf_{l,r,t}fl,r,t​：[l,r][l,r][l,r] 作为一个极小区间时，状态为 ttt 的方案数；
  • gl,r,tg_{l,r,t}gl,r,t​：整个 [l,r][l,r][l,r] 由若干极小区间组成时，状态为 ttt 的方案数；
  • hl,r,t,jh_{l,r,t,j}hl,r,t,j​：在 [l,r][l,r][l,r] 的分解中，左端点 lll 与一个指定极值位于同一个极小区间的方案数。j=1j=1j=1 指定最小值，j=0j=0j=0 指定最大值。

转移：

fl,r,t=∑i=min⁡(sm,bi)max⁡(sm,bi)−1hl,i,t1′,[sm<bi] fi+1,r,t2′.gl,r,t=fl,r,t+∑i=lr−1gl,i,t1′ fi+1,r,t2′.f_{l,r,t}=\sum_{i=\min(sm,bi)}^{\max(sm,bi)-1}h_{l,i,t'_1,[sm<bi]}\,f_{i+1,r,t'_2}.\\ g_{l,r,t}=f_{l,r,t}+\sum_{i=l}^{r-1}g_{l,i,t'_1}\,f_{i+1,r,t'_2}. fl,r,t​=i=min(sm,bi)∑max(sm,bi)−1​hl,i,t1′​,[sm<bi]​fi+1,r,t2′​​.gl,r,t​=fl,r,t​+i=l∑r−1​gl,i,t1′​​fi+1,r,t2′​​.

fff 限制切点落在两个极值之间，ggg 将任意前缀方案与末尾极小区间拼接。

  1. （不漏）每个合法方案可以按其第一个或最后一个极小区间唯一拆分，因此递推不会漏掉方案。
  2. （不重）首段或末段的位置唯一，且相应求和只枚举满足极值位置约束的切点，所以同一规范分解不会被重复计数。

本题总结：

  1. 把重复、交错的操作规范化为连续极小区间的分解
  2. 先寻找一种规范分解，再按“第一个”或“最后一个”局部结构计数
