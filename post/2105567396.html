Section 2.2 Inverse of Matrix

An n×nn\times nn×n matrix AAA is said to be invertible if there is an n×nn\times nn×n matrix CCC such that :

CA=I\and AC=I

In this case is case, CCC is an inverse of AAA, and is uniquely determined by AAA, we can write in A−1A^{-1}A−1.

Theorem

The quantity ad−bcad-bcad−bc is called the determinant of AAA, we can write :

det⁡A=ad−bc\det A=ad-bc detA=ad−bc

Theorem

If AAA is an invertible n×nn\times nn×n matrix, then for each bbb in Rn\R^nRn, the equation Ax=bAx=bAx=b has the unique solution x=A−1bx=A^{-1}bx=A−1b.

Theorem

  1. If AAA is an invertible matrix, then A−1A^{-1}A−1 is invertible and (A−1)−1=A(A^{-1})^{-1}=A(A−1)−1=A
  2. If AAA and BBB are n×nn\times nn×n invertible matrices, then so is ABABAB. Then (AB)−1=B−1A−1(AB)^{-1}=B^{-1}A^{-1}(AB)−1=B−1A−1
  3. If AAA is an invertible matrix, then (AT)−1=(A−1)T(A^T)^{-1}=(A^{-1})^T(AT)−1=(A−1)T

An invertible matrix AAA is row equivalent to a identity matrix.

Elementary Matrices

An elementary matrix is one that is obtained by performing a single elementary row operation on an identity matrix.

If an elementary row operation is performed on an m×nm\times nm×n matrix AAA, the resulting matrix can be written as EAEAEA, where the m×mm\times mm×m matrix EEE is created by performing the same row operation on ImI_mIm​.

Each elementary matrix EEE is invertible. The inverse of EEE is the elementary matrix of the same type that transforms EEE back to AAA.

Theorem

An n×nn\times nn×n matrix AAA is invertible, then any sequence of elementary row operations that reduces AAA to InI_nIn​ also transforms InI_nIn​ to A−1A^{-1}A−1.

If AAA have an inverse, then [A      I][A\;\;\; I][AI] is row equivalent to [I      A][I\;\;\;A][IA].

This provide us an algorithm for finding A−1A^{-1}A−1.

Section 2.3 Characterizations of Invertible Matrices

This statement are all equivalent :

The Invertible Matrix Theorem

If AAA is invertible, then A−1A^{-1}A−1 is invertible and (A−1)−1=A(A^{-1})^{-1}=A(A−1)−1=A

This divide the set of all n×nn\times nn×n into 2 parts:

  • Invertible = Nonsingular
  • Noninvertible = singular

Invertible Linear Transformations

A Linear transformation T:Rn→RnT:\R^n\to \R^nT:Rn→Rn is said to be invertible if there exists a functions S:Rn→RnS:\R^n\to \R^nS:Rn→Rn such that :

  • S(T(x))=xS(T(x))=xS(T(x))=x for all xxx in Rn\R^nRn
  • T(S(x))=xT(S(x))=xT(S(x))=x for all xxx in Rn\R^nRn

We call SSS is the inverse of TTT and write it as T−1T^{-1}T−1.
