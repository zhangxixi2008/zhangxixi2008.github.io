Section 6 Lists

list

A list is an ordered sequence of values

Each value has an index. Indexing is zero-based (counting starts with zero)

list operation

  • List Creation : a = [1, 2, 3]

  • List Querying

    • Single element : mylist[index]

    • Sublist(“slicing”): mylist[start : end] # from start to end - 1

      If start is omitted : defaults to 0

      If end is omitted : defaults to len(mylist)

      mylist[:]

Slicing Examples

Querying

  • x in mylist : Return True if x is found in mylist
  • mylist.index(x) : Return the integer index in the list of the ifrst item whose value is x
  • mylist.count(x) : Return the number of times x appears in the list

List Insertion

  • mylist.append(x) Extend mylist by inserting x at the end

  • mylist.extend(L) Extend mylist by appending all items in the List L to the end of mylist

  • mylist.insert(i, x) Insert item x before position i

    a.insert(len(a), x) is equivalent to a.append(x)

Removing Items from a List

  • mylist.remove(x) : Remove the first item from the list whose value is x

  • mylist.pop([i]) : Remove the item at the given position in the list, and return it.

    If no index is given, mylist.pop() removes and returns the last item in the list.

List Replacement

  • mylist[index] = new_value
  • mylist[start : end] = new_sublist

List Rearrangement

  • mylist.sort()
  • mylist.reverse()

List Slicing Examples
