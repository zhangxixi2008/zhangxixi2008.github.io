Chapter 1: Linear Equations

1. Systems of Linear Equations

  • Equivalence: System   ⟺  \iff⟺ Solution Sets →\to→ Row equivalent.
  • Consistency:
    • Consistent ←\leftarrow← One solution / Infinite solutions.
    • Inconsistent ←\leftarrow← No solution.
  • Matrix Representations:
    • Coefficient Matrix
    • Augmented Matrix

1.1 Row Reduction & Existence

  • Elementary Row Operations: (1) Replacement, (2) Interchange, (3) Scaling.
  • Forms: Echelon Form →\to→ Reduced Echelon Form (Uniqueness).
  • Existence and Uniqueness:
    • No solution if the system contains a row like [0…0 b][0 \dots 0 \ b][0…0 b] where b≠0b \neq 0b=0.
    • Pivot determines basic variables and free variables.
    • Free variables imply infinite solutions (uniqueness fails).

2. Vector Equations

  • Notation: Column vector (a,b)(a, b)(a,b) or [ab]\begin{bmatrix} a \\ b \end{bmatrix}[ab​].
  • Linear Combination: y=c1v1+c2v2+⋯+cnvn⇒[a1,a2…an b]y = c_1v_1 + c_2v_2 + \dots + c_nv_n \Rightarrow [a_1, a_2 \dots a_n \ b]y=c1​v1​+c2​v2​+⋯+cn​vn​⇒[a1​,a2​…an​ b], where cic_ici​ are the weights.
  • Span: ∀c⇒Span{v1…vp}\forall c \Rightarrow \text{Span}\{v_1 \dots v_p\}∀c⇒Span{v1​…vp​}.

3. Matrix Equation

  • Form: Ax=bAx = bAx=b, where AAA is an m×nm \times nm×n matrix and b∈Rmb \in \mathbb{R}^mb∈Rm.
  • Existence of Solutions: bbb is a linear combination of all columns of AAA.

    Ax=[a1,a2…an][x1⋮xn]=x1a1+x2a2+⋯+xnanAx = [a_1, a_2 \dots a_n] \begin{bmatrix} x_1 \\ \vdots \\ x_n \end{bmatrix} = x_1a_1 + x_2a_2 + \dots + x_na_n Ax=[a1​,a2​…an​]​x1​⋮xn​​​=x1​a1​+x2​a2​+⋯+xn​an​

  • Row-vector Rule for Computing AxAxAx: Products of Row iii in AAA and vector xxx.

    [234][x1x2x3]=[2x1+3x2+4x3]\begin{bmatrix} 2 & 3 & 4 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} = [2x_1 + 3x_2 + 4x_3] [2​3​4​]​x1​x2​x3​​​=[2x1​+3x2​+4x3​]

  • Properties:

    A(u+v)=Au+AvA(u+v) = Au + Av A(u+v)=Au+Av

    A(cu)=c(Au)A(cu) = c(Au) A(cu)=c(Au)

4. Solution Sets

4.1 Homogeneous Systems (Ax=0Ax = 0Ax=0)

  • At least a trivial solution exists.
  • Nontrivial solution →\to→ free variable exists.

4.2 Nonhomogeneous Systems (Ax=bAx = bAx=b)

  • General solution form: x⃗=p⃗+tv⃗\vec{x} = \vec{p} + t\vec{v}x=p​+tv, where p⃗\vec{p}p​ is a particular solution.
  • Parametric Vector Form: x⃗=su⃗+tv⃗\vec{x} = s\vec{u} + t\vec{v}x=su+tv.

5. Linear Independence

  • Definition: Only trivial solution exists. If not, it has a linear dependence relation c1v1+c2v2+⋯+cnvn=0c_1v_1 + c_2v_2 + \dots + c_nv_n = 0c1​v1​+c2​v2​+⋯+cn​vn​=0 (where ccc not all zero).
  • Matrix Columns: Linear Independence of Matrix Columns   ⟺  \iff⟺ At least 1 in SSS is a linear combination of others.
  • Rules of Thumb:
    • Vectors > Entries in each vector →\to→ linearly dependent.
    • Zero vector →\to→ linearly dependent.

Linear Transformation

1. Introduction to Linear Transformations

  • Mapping Notation: T:Rn→RmT : \mathbb{R}^n \to \mathbb{R}^mT:Rn→Rm
    • Domain →\to→ Codomain
    • T(x)→T(x) \toT(x)→ Range (Image of xxx)
  • Matrix Transformation: x↦Axx \mapsto Axx↦Ax.
  • Conditions for Linear Transformation (iff):

    T(u⃗+v⃗)=T(u⃗)+T(v⃗)T(\vec{u} + \vec{v}) = T(\vec{u}) + T(\vec{v}) T(u+v)=T(u)+T(v)

    cT(u⃗)=T(cu⃗)cT(\vec{u}) = T(c\vec{u}) cT(u)=T(cu)

    • Implication: T(0)=0T(0) = 0T(0)=0
  • Simplified Form:

    T(cu⃗+dv⃗)=cT(u⃗)+dT(v⃗)T(c\vec{u} + d\vec{v}) = cT(\vec{u}) + dT(\vec{v}) T(cu+dv)=cT(u)+dT(v)

2. The Matrix of a Linear Transformation

  • T:Rn→Rm  ⟹  T: \mathbb{R}^n \to \mathbb{R}^m \impliesT:Rn→Rm⟹ Unique A:Ax=T(x)A : Ax = T(x)A:Ax=T(x).
  • Standard Matrix: A=[T(e1),T(e2)…T(en)]A = [T(e_1), T(e_2) \dots T(e_n)]A=[T(e1​),T(e2​)…T(en​)], where eje_jej​ is the jjj-th column of the Identity Matrix.
