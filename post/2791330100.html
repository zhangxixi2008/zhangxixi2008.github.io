Class Introduction

UCUG1000 CTDL (Critical Thinking & Data Literacy)

CTDL is a course about ONE question:

How do we make good judgements when the answer is not obvious

At university, you will learn many powerful tools:

  • Programming (or vibe coding) helps you build
  • Calculus helps you model
  • AI helps you generate
  • Your major helps you specialize

But you still need to decide :

  • What should I trust?
  • What does the evidence show?
  • Does the conclusion make sense?

Getting answers is easier.

Judging an answer is harder.

Critical Thinnking : How should I reason ?

Data Literacy: How should I use evidence?

Critical Thinking is not tied to one discipline.

You may use the same skills to:

  • evaluate a scientific claim
  • interpreting social data
  • making a bussiness decision

3 credits = 3 modules

  • Module 1 Basics of CTDL : first 5 weeks (Build the fundation for critical thinking and data literacy)
  • Next 8 weeks : 4 weeks each
    • CTDL in Social Science
    • Entrepreneurship
    • Science
    • Engineering
    • Business
    • Technology

In CTDL, expect to:

  • Participate
  • Analyze (Arguments, information, cases, and data)
  • Explain (What you think + Why)
  • Apply
  • Assessment within each module:
    • In-class test (20%) + Written assignment (60%) + Participation (20%)

One thing to remember :

Do no just ask : What is the answer

Ask: How do I know?

UCUG 1001 HMW (Behavioral Foundations of University Education)

A easy start : discover yourself

Compulsory Year-1 Student Academic year

  • Pass / Fail

Both the first and second semesters can receive a Pass

If get an F in this course, it will also have a negative impact on GPA

Outcomes:

  1. A broad and solid knowledge foundation
  2. A curious and inquisitive learning mindset
  3. explore your potential and aspirations
  4. develop the transferable skills
  5. enhance personal well-being

Instructors are from different academic backgrounds.

UCUG1002 Artificial Intelligence General Education

What Counts as AI?

An ablity of machines to perform tasks that normally require human intelligence:

  1. Perception
  2. Learning
  3. Reasonning
  4. Language
  5. Action

AI literacy:

  • Understand : How data, models, and algorithms work
  • Use : Apply AI tools to real problems
  • Question : Test evidence, bias, privacy, and impact

Journey:

  • Weeks 1- 4 : History ; Data Machine Learning ; Deep learning
  • Weeks 5 - 8: Reasoning ; LLMs Explainability ; Ethics & Governance
  • Weeks 9 - 13 : AI + X; Choose a domain; Build a project (Need to choose)

It set Pass / Fail

Individual work:

  1. Two assignments : 60%
  2. In class text 20%
  3. One proect 20%
