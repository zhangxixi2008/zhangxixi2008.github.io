Section 1.5 Solution Sets of Linear Systems

Homogeneous Linear Systems :

  • Homogeneous if it can be written in Ax=0Ax=0Ax=0
  • Such Ax=0Ax=0Ax=0 always has at least one solution, called trivial solution
  • Ax=0Ax=0Ax=0 has a nontrivial solution iff the equation has at least one free variable

Parametric Vector Form : x⃗=su⃗+tv⃗\vec x=s\vec u+t\vec vx=su+tv

Solutions of Nonhomogeneous System : x⃗=p⃗+tv⃗\vec x=\vec p+t\vec vx=p​+tv. Note that p⃗\vec pp​ itself is just one particular solution.

Theorem : Suppose the equation Ax=bAx=bAx=b is consistent for some given bbb, and let ppp be a solution. Then the solution set of Ax=bAx=bAx=b is the set of all vectors of the form w=p+vhw=p+v_hw=p+vh​, where vhv_hvh​ is any solution of the homogeneous equation Ax=0Ax=0Ax=0.

Section 1.7 Linear Independence

Definition of linear independence : the vector equation x1v1+x2v2+⋯+xpvp=0x_1v_1+x_2v_2+\cdots+x_pv_p=0x1​v1​+x2​v2​+⋯+xp​vp​=0 has only the trivial solution.

Linear dependence relation : c1v1+c2v2+⋯+cnvn=0c_1v_1+c_2v_2+\cdots+c_nv_n=0c1​v1​+c2​v2​+⋯+cn​vn​=0, where the weights cic_ici​ are not all zero.

Linear Independence of Matrix Columns : iff Ax=0Ax=0Ax=0 only have trivial solution.

Sets of One, Two or More Vectors:

  • One vector : is linearly independent iff vvv is not the zero vector.
  • Two vector : Just by inspection
  • More vectors: set S={v1,v2,…,vn}S=\{v_1,v_2,\dots,v_n\}S={v1​,v2​,…,vn​} is linearly dependent iff at least one vectors in SSS is a linear combination of the others. (Not for every vector)

Theorem : If a set contains more vectors than the entries in each vector, then the set is linearly dependent.

Theorem : If a set contains zero vector, then the set is linearly dependent.
