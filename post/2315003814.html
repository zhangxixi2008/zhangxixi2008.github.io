Play It by Ear - Problem - QOJ.ac

令 posxpos_xposx​ 表示编号为 xxx 的牌在原先牌堆的位置。

设 fif_ifi​ 表示完成第 iii 步（aia_iai​ 牌打出），至少需要多少步。设对于 aia_iai​ 这张牌，上一次出现在 preipre_iprei​ 的位置，那样子有：

fi≥fi−1+1fi≥fprei+n+1f_i\ge f_{i-1}+1\\ f_i\ge f_{pre_i} + n + 1 fi​≥fi−1​+1fi​≥fprei​​+n+1

因为上一张牌打完之后至少要 nnn 轮后才能回到手中，再经过一轮才能打出来。

当然，如果这张牌是第一次出现，那也必须满足：fi≥posai−n+1f_i\ge pos_{a_i} - n + 1fi​≥posai​​−n+1，你要先拿到手里，然后再打出。

那么总共需要的轮数是 fmf_mfm​。

这种一定能达到吗？我们考虑这个策略：

  1. 如果有需要的，立刻打
  2. 否则，打最晚需要的那一张。但至少目前手上有 n−1n-1n−1 张，还有1张不需要的要等。因此当前打出来这张至少在 nnn 轮后才需要，因此完全来得及。

我们要求 fmf_mfm​ 的期望值，我们设为 kkk，那么我们可以先考虑对于每个 kkk 有多少种合法的初始牌堆满足。那样子我们是能求出 posipos_iposi​ 的上界，而求 posipos_iposi​ 上界的过程相当于解很多具有有序性的不等式，我们要满足最严格的限制，那就反向跑个最长路即可（其实就是一个链状DAG上dp）

考虑我们求出从 mmm 到每个位置的最长路 wiw_iwi​，然后假设对于牌 xxx，第一次在 iii 的地方出现，那就要满足：

max⁡(0,posi−n+1)≤fi=k−wi\max(0,pos_i-n + 1)\le f_i=k - w_i max(0,posi​−n+1)≤fi​=k−wi​

令 Li=k+n−wi−1L_i=k + n - w_i-1Li​=k+n−wi​−1 代表 posipos_iposi​ 的上界，注意 LiL_iLi​ 还要和 2n2n2n 取min。

接下来就简单了，对 LiL_iLi​ 排序，然后得到 Li′L_i'Li′​，那样子期望步数小于等于 kkk 的方案为：

C(k)=∏i=12n(Li−i+1)C(k)=\prod_{i=1}^{2n}(L_i-i+1) C(k)=i=1∏2n​(Li​−i+1)

接下来对 CCC 做一个差分即可。

可以发现，有效的 kkk 的取值至多 n+1n+1n+1 个（实际上是 nnn 个）。kkk 的最小有效值是 w0w_0w0​，代入 (k−w0)+n−1(k-w_0)+n-1(k−w0​)+n−1，也就是 kkk 增加 n+1n+1n+1 次之后必然达到 2n2n2n 了。

还有，我们不可能每次都对 LiL_iLi​ 排序一遍，但可以发现 LiL_iLi​ 的顺序是不变的，所以提前排一次就行了。
