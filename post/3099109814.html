Signed Binary Numbers

Way 1 : let the first bit be the sign bit, then the remaining digit be the magnitude bits, but failed for the addition.

Way 2 : Use the 2’s complement code, and the addition is also the 2’s complement code of the answer.

Conclusion:

  • Positive or 0 : binary code
  • Negative : 2’s complement of AAA

So for a 8-bit number : 00000000 - 11111111 :

  • If the first bit is 0, is the positive number or zero

  • If the first bit is 1, then is the 2’s complement code

    Eg : 10000000 is -128, 10000001 is -127, 11111111 is -1

And when 2 numbers are added together with two different signed, it will never be overflow!

Update on 2026.9.15:

In fact, don’t need to distinguish positive and negative numbers distinctly. Just regard the first bit as −128-128−128 !
