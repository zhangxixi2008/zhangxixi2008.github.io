1. Python 库与 NumPy

对应课件第 2–11 页。

1.1 什么是 Python 库？

库（library）是一组可复用的模块，提供函数、类和方法，帮助完成数据处理、数学计算、网页抓取等常见任务。使用库可以减少重复编写代码，让程序更简洁。

通过 import 导入后，可以使用库中已有的功能：

多数 Python 库包含 .py 源文件；为了提高性能，也可能包含编译扩展，例如 Windows 的 .pyd、.dll，以及 Linux/macOS 的 .so。

1.2 NumPy 是什么？

  • NumPy 是 Numerical Python 的缩写，是用于数值计算的开源 Python 库。
  • 由 Travis Oliphant 于 2005 年创建。
  • 核心数据结构是 ndarray（N-dimensional array，多维数组）。
  • 提供数组操作、线性代数、傅里叶变换等功能，广泛用于数据科学和机器学习。

1.3 为什么使用 NumPy？

Python 的 list 可以存放一组数据；NumPy 的数组更适合大量数值数据的存储和批量计算。

NumPy 高效的主要原因：

  1. 数值数组的数据通常紧凑存储，有利于局部性（locality of reference）和缓存利用。
  2. 许多计算由底层编译代码完成，减少 Python 逐元素循环的开销。
  3. 底层实现会针对 CPU 进行优化。

**补充说明：**课件提到 NumPy “可比 Python 列表快多达 50 倍”，这是特定任务中的示意性比较，并非所有操作都有固定倍数的提升。数组也不一定连续存储，例如某些切片视图；Python 列表本身通常连续存放对象引用，数值对象则可能分散存储。

1.4 数组在实际数据中的含义

维度 常见数据 理解方式
一维（1-D） 音频波形、速度随时间变化的数据 一串采样值
二维（2-D） 灰度图像、频谱图、矩阵 行 × 列
三维（3-D） RGB 图像、MRI 体数据 高度 × 宽度 × 通道，或三维空间网格

例如，RGB 图像的一个像素由红、绿、蓝三个通道值表示，因此常用形状为 (height, width, 3) 的数组存储。

课件的图像处理示例展示了：原图 − 平滑图 = 细节图。提取出的细节可用于增强图像边缘和锐度。

**补充说明：**张量（tensor）可以有不同维度，不专指三维数组；二维图像示例通常指灰度图像。

数组维度可以理解为数组的轴数，也可以通过嵌套层级理解。

补充说明：np.sort(arr) 与 arr.sort() 的行为不同：

写法 原数组是否改变 返回值
np.sort(arr) 否 排好序的新数组

12.2 高频易错点

  1. **维度不等于元素个数。**形状 (2, 3) 的数组有 2 个轴、6 个元素。
  2. **索引从 0 开始。**第一行、第二列对应 arr[0, 1]。
  3. 切片不包含终点。arr[1:5] 取索引 1 到 4。
  4. 整数索引和切片对形状的影响不同。arr[:, 2] 与 arr[:, 2:3] 不同形状。
  5. 赋值、视图和副本不同。x = arr 引用同一对象；view() 是共享数据的新对象；copy() 复制数据。
  6. **基本切片通常共享数据。**需要独立数据时可写 arr[1:4].copy()。
  7. reshape() 不改变元素总数，也不保证总是返回视图。
  8. 二维拼接要看结果。axis=0 增加行数，axis=1 增加列数。
  9. **二维排序默认按行内部排序。**不会自动把整个矩阵当成一串数据进行全局排序。
  10. 查找位置与筛选数值不同。where(condition) 给索引，arr[condition] 给元素。

12.3 自测题（补充）

设：

  1. a.ndim 和 a.shape 分别是多少？
  2. a[1, -1] 的结果是什么？
  3. a[:, 1:3] 的结果是什么？
  4. a.reshape(3, 2) 是否可行？a.reshape(4, 2) 呢？
  5. np.where(a > 3) 与 a[a > 3] 有什么区别？

参考答案：

  1. 2 和 (2, 3)。
  2. 6。
  3. [[2, 3], [5, 6]]，形状为 (2, 2)。
  4. 前者可行，因为 3 × 2 = 6；后者不可行，因为 4 × 2 != 6。
  5. 前者返回 (array([1, 1, 1]), array([0, 1, 2]))，按行、列给出位置；后者返回 [4 5 6]，直接给出数值。
