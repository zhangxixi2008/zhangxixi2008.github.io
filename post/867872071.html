PyCharm Install and Basic Use

Install

https://www.jetbrains.com/pycharm/download/

Two important :

  1. Add “bin” folder to PATH
  2. Associate .py to pycharm

Start Coding

  1. Create Project : “New project”, choose location, keep the default Project venv
  2. Create a python file on the left windows

Run

Two ways:

  2. First Right Click and

If counter:

Choose the “Create a virtual environment” is ok (If you have installed python)

Use

Bigger the editor

Settings -> General -> Mouse Control

Choose “All editors” is ok.

Full Screen

Fast keys

  • Shift x 2 : Search
  • Crtl + / : Comment
